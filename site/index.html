Your GitHub token

Starting a video needs a token. Watching and downloading videos does not.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → this repository.
  3. Permissions → Repository permissions: Actions: Read and write. Add Contents: Read and write too if you want to delete videos from here.
  4. Pick an expiry, press Generate token, copy it and paste it below.

The token stays in this browser and is only sent to api.github.com. Without "Remember" it is gone when you close the tab.
